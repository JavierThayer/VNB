# slides/ -- the VNB talks

    slides/
      Makefile        build and regenerate
      outline.md      the agreed shape, part by part
      shared/         everything LANGUAGE-NEUTRAL, included by both decks
        preamble.tex    packages, theme, macros
        numbers.tex     every quoted figure, with its source command and date
        code/           source listings, EXTRACTED from the tree (MANIFEST)
        proofs/         natural-language proofs, EMITTED by the checker
      en/main.tex     the English deck
      es/main.tex     the Spanish talk -- a DIFFERENT talk, not a translation

## Build

    make            # English deck -> en/main.pdf
    make code       # regenerate shared/code/*.txt from the source tree
    make proofs     # regenerate shared/proofs/*.tex by running the checker
    make figures    # structure graph: reference/structure-graph.dot -> PDF
    make clean

`make proofs` loads the library, so it wants a compiled tree (see CLAUDE.md:
interpreted, the same load costs about eleven minutes instead of twenty-four
seconds).

## The design, in one sentence

Nothing on a slide is transcribed by hand from something that can change.

* **Code listings** are cut from the real files by `shared/code/extract.sh`,
  driven by `shared/code/MANIFEST` (output, source path, line range). The line
  ranges are the fragile part: re-run `make code` and read the diff before a
  talk. `bills.txt` is the worst of them and needs reading rather than
  trusting: its source, `reference/PROOF-DEBT.md`, is REGENERATED by every
  library load, so its entries move whenever a theorem is added or a bill
  changes. A range that has drifted is usually still *valid*, so the extractor
  reports success and the slide shows a different theorem's bill. That happened
  on 2026-08-10 and the slide kept showing a debt that had been discharged.
* **Proofs** are what `proof-reader` emits, unedited --- `make proofs` runs
  `shared/proofs/regen.scm` through the checker and strips the preamble (and
  the `enumitem` options on `itemize`, which beamer refuses). Hand-polishing
  them would misrepresent the tool on stage; the gap between what the reader
  says and what a mathematician would write is one of the things the talk is
  about.
* **The structure graph** is `dot`-rendered from `reference/structure-graph.dot`,
  which the prover writes from its own registry --- so the picture cannot show
  a hierarchy the system does not have. `-Gratio=0.55` stretches the layout to
  roughly 16:9 without changing the node boxes; regenerate the `.dot` from a
  REPL with `(structure-graph-dot-file)` when the hierarchy moves.
* **Numbers** live in `shared/numbers.tex`, one macro each, each with the
  command that produced it and the date. Refreshing the figures before a talk
  is one file.
* **`es/` is not a translation.** It is a different talk: general audience,
  time limited (45 min), arriving at VNB rather than being about it. There will
  be no translation of the technical deck. Consequently `make parity` --- which
  diffed the `\fid{...}` frame skeletons of the two decks and failed the build
  when they diverged --- was **retired on 2026-08-11**. It was the right gate
  for a translation and the wrong one for this, and a gate whose premise is
  false is worse than no gate. The `\fid{...}` markers stay in `en/main.tex`:
  they typeset nothing and are still the stable way to name a frame once the
  page numbers have moved.

## Still open

* ~~The Spanish deck.~~ **Written** (2026-08-11, 24 pages, `make es`): a general
  talk for a 45-minute slot, not a translation and not derived from this deck.
  The *macete* terminology question never arose --- the word does not appear in
  it.
* **The assessment frame** (`\fid{llm-assessment}`) is deliberately an empty
  box: the speaker's verdict on the claimed applications of language models to
  mathematics, in his own phrasing, replaces it.
* **Length is not a constraint** (2026-08-09). The deck is a **superset** from
  which an actual talk selects --- slides are skipped on the day. A frame
  earns its place by carrying something, and no frame should depend on the
  audience having seen every one before it. Cross-references are therefore
  written as "a later slide", never "later in the talk".
* **For now it is emailed, not presented.** It is read without a speaker, so
  every frame has to stand on its own text; a line that only works when spoken
  over does not belong. This is the technical deck.
* **The general talk in Spanish is a different object** and **is** time limited
  (45 min). Written; nothing was recycled from here without cutting. Its build
  has one wrinkle worth knowing: this machine has no `texlive-lang-spanish`, so
  `\usepackage[spanish]{babel}` aborts the build and `es/main.tex` disables
  hyphenation instead --- see the comment at its head.
* The `metric-sym` frame uses `[shrink=25]` on purpose --- the whole proof on
  one slide, too small to read, because its *shape* is the argument. If the
  speaker would rather walk through it, split it and drop the shrink.
