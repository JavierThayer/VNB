**The new theorems, stated after the source.**

* `regulated-on-reflect` (Dieudonne VII.6, the definition of a regulated function; the reflection
  is not stated separately in the source, and 8.7.4 calls the analogous step immediate): if f is
  regulated on [a, b] and c is real, then t -> c f(a + b - t) is regulated on [a, b]. The scalar
  is there because the opposite road's derivative is -dgamma(a + b - t); without it a second
  lemma would be owed.
* `reflect-image-countable`: the reflection of a countable subset of [a, b] is a countable
  subset of [a, b] (`countable-image`).
* `nondecreasing-off-countable` and `nondecreasing-off-countable-on-interval`: a continuous
  function whose derivative is >= 0 off a countable set is nondecreasing. Proven from the mean
  value inequality with a countable exceptional set (Dieudonne 8.5.3, `mvi-off-countable`) applied
  to -h at bound 0, not from the strict-sign monotonicity law, which needs a strictly negative
  derivative.
* `is-road-re-regulated`, `is-road-im-regulated`: the two regulated clauses of `IS-ROAD`, as
  citable read-offs.
