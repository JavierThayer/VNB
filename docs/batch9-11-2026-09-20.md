## 3. The kernel checks what it records

`dg-apply-rule!` verifies every inference BEFORE writing it: one checker per kernel operation
(`rule-checkers-{logic,schema,rewrite,oracle}.scm`), written independently of the procedure that
built the hypotheses, as a relation between conclusion and hypotheses. No checker, or a refusal, is
an error and nothing is written; a refusal prints even inside `quietly`; the load reports the count.

checkers verify by arithmetic. Cost: +30% load time. Each checker has an accepted and a refused
control in the suite.
