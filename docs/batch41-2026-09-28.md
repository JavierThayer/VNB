## What was built

**The rule language** (`preamble.scm`, prefix `pa-`; `preambles/default.pre`). A rule is
`(rule NAME (goal P) (with P)* (guard G ...)* (do FORM) [(probe ...)] [(side ...)])`, read by `read`; patterns
are the raw S-expressions the goals have, with schema variables `?x`, matched by a wrapper over the
rewriter's `match-expr` (goal first, then the `with` patterns against the assumptions with shared bindings and
backtracking; a `?x` in binder position binds the bound variable's name). Guards: `typed`, `head`, `closed`,
`not-in-context`, and three the default rules needed, `one-of`, `occurs`, `unfolds`. Probes: `grounded`,
`progress` (default), `changed`, `(lands F)`. A malformed rule is left out and reported by name.

**The command** `(preamble)`, `(preamble 'NAME)`, `(preamble "file.pre")`: the rules of the argument, else
`~/.vnb-preamble.pre` when it exists, else the shipped default. On the focus leaf, the first matching rule is
fired on a scratch copy, then on the proof inside a transaction, and kept only when its probe holds both
times; the loop restarts on the new focus and stops at done, owed, stalled, cap (40) or error. Each kept
firing is recorded AS ITSELF, so the page is ordinary steps and replays with no rule file present (four
preamble-driven proofs were qed'd and their pages type back in grounded). The report is one block on the
report channel (what fired and what it did, what matched and was rejected and why, what raised, the OWED
claims, where it stopped); the value is a verdict alist. A `(cut F)` action is a TENTATIVE CUT: the rules run
on the side leaf and either prove it in place or roll back and report it as owed, by formula; nothing installs
a support. Two pure entry points for phase 2, `preamble-propose` and `preamble-attribute`, are in and checked.

**The default rules**, in order: peel-universal, peel-implication, split-conjunction, close-by-context,
reflexivity, quasi-reflexivity, ground-arithmetic, type-arithmetic-term (the user's clause: `type-term`),
type-by-context, type-by-in-rr, modus-ponens, instance-of-universal, ring-equation (`zero-it`), real-order-le
and -lt (`pa-ineq!`: contra's lifts and premise filter, then `ineq`), beta-redex, sep-membership,

## What was found

1. **`supply` records none of its steps** (`ineq-supply.scm` drives `lam-b`, `fact`, `ineq` through
   `apply-recorded-cmd!`, which bypasses `vnb--run!`): a proof it closes qeds, and its page types back
   `incomplete`. Reproduced. No library proof uses it. Fix: record each step, or record `(supply)` with a
   replay case.
2. **The rule language cannot bind the instance of a universal hypothesis** whose conclusion is the goal, so
   the tentative cut handles plain implications only. A guard `(instance ?u ?g ?inst)` would widen it.
3. **`use` sweeps every open leaf**, so the unfold rules use `mac`.
4. **`type-term` pages are long**: the degree-3 typing records 220 steps (a cut, a focus and a fact per
   subterm, `crs` per power). Recording `(type-term)` as one step, as `zero-it` does, is a decision about
   `type-term`.
5. **The tree's `any` returns `#t`, not the value found** (`sequents.scm:462` shadows SRFI-1): code written
   against SRFI-1 trips on it silently.
6. **The `closed` guard is true of a closed sentence**, so ground-arithmetic matches a closed universal and is
   then rejected by `arith`: correct, visible in the panel's lane.
