# The tree, grouped

The files of `prover/` by role, generated by `build-vnb-view.sh` from the
same grouping as the symlinked view `~/vnb`; every name is a link into this
repository.  `structure-library/` (definitions, structures, vocabulary) and
`theorem-library/` (proofs) keep their own directories; the groups below sort
the files at the root and the structure library by theory.
