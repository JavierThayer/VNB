# Proof printouts (LaTeX step-traces)

Generated by proof-tex (`(view-proof-pdf 'NAME)` / `(write-proof-tex 'NAME path)`).
Each shows: a tactics-used glossary, a notation glossary, and a numbered
derivation where every step lists the nodes it opens + the focus node and the
focus node's assumptions.

**Now rendered by LIVE CAPTURE** (the focus is snapshot as the proof actually
runs, no replay), so the forward-`fact` proofs that defeated the old replay --
including the CHOICE-technique proofs -- render faithfully.  To regenerate a
calculus proof: run its script with `-i`, then `(write-proof-tex 'NAME
"calculus/printouts/NAME.tex")` in the same process, then `pdflatex`.

## Choice technique (ε-as-function: VNB-LAMBDA ∘ global CHOICE)
- chosen-centre-is-centre.pdf      the ε pick is a genuine ball centre
- finite-ball-subcover-r-net.pdf   finite subcover => CENTRE-SET is a finite r-net
- gauge-is-degree.pdf              the named Euclidean GAUGE is a valid degree fn

Read these three together to see the mechanism: a defined set of valid
witnesses (CENTRES / EUCLIDEAN-GAUGES), `choice-axiom` lands in it because it is
inhabited (the iota/ε definedness proviso), and the SEP slices read the picked
element's defining properties back off.
