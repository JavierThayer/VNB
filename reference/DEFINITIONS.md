## Recursively-defined functoids

Defined by primitive recursion on `NN` (`def-by-nn-recursion`): a `name-zero` base and a `name-succ` step.  The extra parameters range over a class (a ring, a monoid, ...), so each is a **functoid**, not a function.

### comb-kk

    forall([r, x, y], comb-kk(r, x, y, 0) == vnb-lambda(k, if(k = 0, one(r), zero(r))))

    forall([r, x, y, m in nn], comb-kk(r, x, y, succ(m)) == vnb-lambda(k, (add(r))((mul(r))(x, (comb-kk(r, x, y, m))(k - 1)), (mul(r))(y, (comb-kk(r, x, y, m))(k)))))

### factorial

    factorial(0) = succ(0)

    forall([k in nn], factorial(succ(k)) = succ(k) * factorial(k))

### falling

    forall([n], falling(n, 0) == succ(0))

    forall([n, k in nn], falling(n, succ(k)) == (n - k) * falling(n, k))

### mpow

    forall([m, x], mpow(m, x, 0) == id(m))

    forall([m, x, n in nn], mpow(m, x, succ(n)) == (mul(m))(x, mpow(m, x, n)))

### nth-deriv

    forall([f], nth-deriv(f, 0) == f)

    forall([f, n in nn], nth-deriv(f, succ(n)) == vnb-lambda(x, deriv(nth-deriv(f, n), x)))

    forall([op, f], reduce(op, f, 1) == f(0))

    forall([alpha, beta], <_ord(alpha, beta) iff <=_ord(alpha, beta) and not(alpha = beta))

### preimage-membership

    forall([s, f, v, a], a in preimage(s, f, v) iff a in pts(s) and f(a) in v)

### reduce-one

    forall([op, f], reduce(op, f, 1) == f(0))

### rr-pos-star-membership

    forall([x], x in rr+* iff x in rr and 0 <= x or x = pos-inf)

### rr-star-membership

    forall([x], x in rr* iff x in rr or x = pos-inf or x = neg-inf)
