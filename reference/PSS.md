## Inequalities & order  (76)

### amgm-2-sqrt

    forall([a], a in rr and 0 <= a implies forall([b], b in rr and 0 <= b implies sqrt(a * b) <= /(a + b, 2)))

*Warrant (well-known):* Geometric mean <= arithmetic mean (two terms):  sqrt(a*b) <= (a+b)/2 for
   a,b >= 0.  Squaring is the SOS fact 4ab <= (a+b)^2 (rr-amgm-2).

### bdd-fn-le-arg

    forall([t in rr], 0 <= t implies /(t, 1 + t) <= t)

*Warrant (well-known):* t/(1+t) <= t for t >= 0: equivalent to t <= t*(1+t) = t + t^2, i.e.
   0 <= t^2.  Gives one half of the topological equivalence d/(1+d) ~ d (the
   identity from (X,d) to (X, d/(1+d)) is 1-Lipschitz, hence continuous).

### bdd-fn-lt-one

    forall([t in rr], 0 <= t implies /(t, 1 + t) < 1)

*Warrant (well-known):* t/(1+t) < 1 for t >= 0: equivalent to t < 1+t, i.e. 0 < 1.  This is what
   makes the derived metric d/(1+d) bounded (every distance < 1).

### bdd-fn-mono

    forall([s in rr, t in rr], 0 <= s and s <= t implies /(s, 1 + s) <= /(t, 1 + t))

*Warrant (well-known):* t/(1+t) = 1 - 1/(1+t) is increasing on [0,oo): s <= t gives 1/(1+t) <=
   1/(1+s).  Lets the triangle inequality for d be pushed through f.

### bdd-fn-nonneg

    forall([t in rr], 0 <= t implies 0 <= /(t, 1 + t))

*Warrant (well-known):* t/(1+t) >= 0 for t >= 0: numerator and denominator are both nonnegative
   (and 1+t >= 1 > 0).

### bdd-fn-subadd

    forall([a in rr, b in rr], 0 <= a and 0 <= b implies /(a + b, 1 + a + b) <= /(a, 1 + a) + /(b, 1 + b))

*Warrant (well-known):* Subadditivity of f(t)=t/(1+t) on [0,oo):  f(a+b) <= f(a)+f(b).  Since
   1+a+b >= 1+a and 1+a+b >= 1+b,  (a+b)/(1+a+b) = a/(1+a+b) + b/(1+a+b) <=
   a/(1+a) + b/(1+b).  This is the fact that makes d/(1+d) satisfy the triangle
   inequality, hence be a metric.  See [[bounded-metric]].

### bernoulli-rpow

    forall([x], x in rr and 0 < 1 + x implies forall([b], b in qq and 1 <= b implies 1 + b * x <= rpow(1 + x, b)))

*Warrant (well-known):* Bernoulli with real exponent:  (1+x)^b >= 1 + b*x  for 1+x > 0 and rational
   b >= 1 (convexity of t |-> (1+x)^t, or t^b).  For 0 <= b <= 1 the inequality
   reverses; stated here for the b >= 1 branch.

### cauchy-schwarz-finite

    forall([s], s in set and card(s) in nn implies forall([a in fun(s, rr), b in fun(s, rr)], finsum(commutative-ring-additive-ag(rr-normed-field), vnb-lambda(i, a(i) * b(i)), s) * finsum(commutative-ring-additive-ag(rr-normed-field), vnb-lambda(i, a(i) * b(i)), s) <= finsum(commutative-ring-additive-ag(rr-normed-field), vnb-lambda(i, a(i) * a(i)), s) * finsum(commutative-ring-additive-ag(rr-normed-field), vnb-lambda(i, b(i) * b(i)), s)))

*In words:* For any finite index set S and real vectors a, b on S: the square of the dot product SUM a(i)*b(i) is at most the product of the two squared norms, (SUM a(i)^2)*(SUM b(i)^2).  Cauchy-Schwarz for finite sums, square form.

*Warrant (well-known):* Cauchy-Schwarz for finite sums:  (SUM a_i b_i)^2 <= (SUM a_i^2)(SUM b_i^2).
   The difference is the Lagrange identity SUM_{i<j} (a_i b_j - a_j b_i)^2 >= 0
   (a finite sum of squares).  Square form -- the root form is
   cauchy-schwarz-sqrt below (now that SQRT exists, real-powers.scm).

### cauchy-schwarz-sqrt

    forall([s], s in set and card(s) in nn implies forall([a in fun(s, rr), b in fun(s, rr)], abs(finsum(commutative-ring-additive-ag(rr-normed-field), vnb-lambda(i, a(i) * b(i)), s)) <= sqrt(finsum(commutative-ring-additive-ag(rr-normed-field), vnb-lambda(i, a(i) * a(i)), s)) * sqrt(finsum(commutative-ring-additive-ag(rr-normed-field), vnb-lambda(i, b(i) * b(i)), s))))

*Warrant (well-known):* Cauchy-Schwarz, root form:  |SUM a_i b_i| <= sqrt(SUM a_i^2) * sqrt(SUM b_i^2).
   Take square roots in cauchy-schwarz-finite (both sides nonnegative); the
   left side is bounded using |SUM| <= sqrt((SUM)^2).

### finsum-abs-triangle

    forall([s], s in set and card(s) in nn implies forall([a in fun(s, rr)], abs(finsum(commutative-ring-additive-ag(rr-normed-field), a, s)) <= finsum(commutative-ring-additive-ag(rr-normed-field), vnb-lambda(i, abs(a(i))), s)))

### finsum-le-termwise

*Warrant (well-known):* Monotonicity of the finite sum: if a(i) <= b(i) for every index i in S then
   SUM_i a(i) <= SUM_i b(i).  Termwise application of rr-le-add over S.

### finsum-sq-nonneg

    forall([s], s in set and card(s) in nn implies forall([a in fun(s, rr)], 0 <= finsum(commutative-ring-additive-ag(rr-normed-field), vnb-lambda(i, a(i) * a(i)), s)))

### holder-finite

    forall([s], s in set and card(s) in nn implies forall([a in fun(s, rr), b in fun(s, rr), p], p in qq and 1 < p implies forall([q], q in qq and 1 < q implies /(1, p) + /(1, q) = 1 implies finsum(commutative-ring-additive-ag(rr-normed-field), vnb-lambda(i, abs(a(i) * b(i))), s) <= rpow(finsum(commutative-ring-additive-ag(rr-normed-field), vnb-lambda(i, rpow(abs(a(i)), p)), s), /(1, p)) * rpow(finsum(commutative-ring-additive-ag(rr-normed-field), vnb-lambda(i, rpow(abs(b(i)), q)), s), /(1, q)))))

*In words:* For any finite index set S, real vectors a, b on S, and conjugate exponents p,q>1 (rational, 1/p+1/q=1): the sum of |a(i)*b(i)| over S is at most the product of the p-norm of a and the q-norm of b -- (SUM |a_i|^p)^(1/p) times (SUM |b_i|^q)^(1/q).  Holder's inequality for finite sums.

*Warrant (well-known):* Hoelder's inequality:  SUM |a_i b_i| <= (SUM |a_i|^p)^(1/p) (SUM |b_i|^q)^(1/q)
   for conjugate exponents 1/p+1/q=1 (p,q>1).  Termwise Young (young-inequality)
   on the normalised vectors, summed.  Cauchy-Schwarz is the p=q=2 case.  Zero
   entries are handled by the 0^p=0 convention (rpow-zero-base).

### minkowski-l2

    forall([s], s in set and card(s) in nn implies forall([a in fun(s, rr), b in fun(s, rr)], sqrt(finsum(commutative-ring-additive-ag(rr-normed-field), vnb-lambda(i, (a(i) + b(i)) * (a(i) + b(i))), s)) <= sqrt(finsum(commutative-ring-additive-ag(rr-normed-field), vnb-lambda(i, a(i) * a(i)), s)) + sqrt(finsum(commutative-ring-additive-ag(rr-normed-field), vnb-lambda(i, b(i) * b(i)), s))))

### block-family

### prod-of-sums-expansion

### cauchy-cluster-converges

*Warrant (well-known):* A Cauchy sequence with a cluster point x converges to x.  Given eps > 0:

### ball-2r-triangle

    forall([s], is-metric-space(s) implies forall([x in pts(s), r], r in rr and 0 <= r and not(0 = r) implies forall([y in ball(s, x, r), z in ball(s, x, r)], (dist(s))(y, z) <= r + r and not((dist(s))(y, z) = r + r))))

*Warrant (proof):* metric-triangle: d(y,z) <= d(y,x)+d(x,z).  Each of d(y,x)=d(x,y) (metric-sym) and d(x,z) is < r by ball-membership, so d(y,z) < r+r.

*Warrant (proof):* metric-self-zero gives d(s)(x,x)=0, so 0<=r and 0!=r (r>0) put x into the SEP; ball-membership then gives x in BALL(s,x,r).

### ball-cover-is-open-cover

*Warrant (well-known):* The r-ball cover { B(x,r) : x in PTS(s) } is an open cover for r > 0: each
   ball is open (ball-is-open), and the union is all of PTS(s) because every
   point x lies in its own ball B(x,r) (d(x,x)=0 < r).

### ball-is-open

    forall([s], is-metric-space(s) implies forall([x in pts(s), r], r in rr and 0 <= r and not(0 = r) implies is-open(s, ball(s, x, r))))

*Warrant (proof):* For y in BALL(s,x,r) the slack t = r - DIST(s)(x,y) is > 0 (ball-membership); the triangle inequality (metric-triangle) gives BALL(s,y,t) subset BALL(s,x,r), so y is interior. Hence BALL(s,x,r) is open.

### ball-mem-from-le

    forall([s], is-metric-space(s) implies forall([x, y, d, r], y in pts(s) and d in rr and r in rr and (dist(s))(x, y) <= d and d < r implies y in ball(s, x, r)))

*Warrant (proof):* d(x,y) <= d and d <= r (from d < r) give d(x,y) <= r by rr-leq-transitive. And d(x,y) = r would give r <= d (substituting into d(x,y) <= d), contradicting d < r by rr-leq-antisymmetric; so d(x,y) != r. With y in PTS(s), ball-membership yields y in BALL(s,x,r).

### carrier-is-open

    forall([s], is-metric-space(s) implies is-open(s, pts(s)))

*Warrant (proof):* SUBSET(PTS(s),PTS(s)) is reflexivity; at each point pick any r > 0, and BALL(s,y,r) subset PTS(s) (a SEP over PTS(s), via the kernel sep rule).

### ccint-membership

*Warrant (proof):* Separation: x in CCINT(a,b) = SEP(x in RR | a<=x and x<=b) iff x in RR and
   a<=x and x<=b, by the SEP membership kernel rule.

### closed-preimage-implies-continuous

    forall([s, t, f], is-metric-space(s) and is-metric-space(t) and f in fun(pts(s), pts(t)) implies forall([a], is-closed(t, a) implies is-closed(s, preimage(s, f, a))) implies is-continuous(s, t, f))

*Warrant (well-known):* rho = d/(1+d) is a metric.  Nonnegativity, symmetry and the zero law come

   RR enters only through the well-definedness of d-hat.  Asserted library-phase

*Warrant (well-known):* Carrier QUOTIENT(CAUCHY-SETOID(M)) is a set (quotient-is-set, setoid.scm).

   arguments: well-defined (the limit exists -- DIST-SEQ is Cauchy in the

   it inherits the metric laws from d -- nonnegativity and symmetry pointwise
   then in the limit; the triangle inequality in the limit; and d-hat([f],[g])=0

## Set & quotient constructions  (6)

### cauchy-setoid-is-setoid

    forall([m], is-metric-space(m) implies is-setoid(cauchy-setoid(m)))

*Warrant (well-known):* CREL(M) subset CARTESIAN(CSEQ,CSEQ) by construction, and null distance is an
   equivalence relation on Cauchy sequences: REFLEXIVE since d(f_n,f_n)=0 -> 0;
   SYMMETRIC since d is symmetric, so d(f_n,g_n) and d(g_n,f_n) are the same
   real sequence; TRANSITIVE since d(f_n,h_n) <= d(f_n,g_n)+d(g_n,h_n)
   (triangle), and a sum of two null real sequences is null.  So IS-SETOID
   (the is-equivalence property folded into it) holds.

### class-disjoint

    forall([s], is-setoid(s) implies forall([a in pts(s), b in pts(s)], class(s, a) = class(s, b) or intersection(class(s, a), class(s, b)) = empty-set))

*Warrant (well-known):* If [a],[b] share a c then a~c and b~c, so a~b (transitivity+symmetry) and
   [a]=[b] by class-eq-iff.  Contrapositive: distinct classes meet emptily.
   Together with class-self (cover) this is `QUOTIENT(s) partitions PTS(s)'.

### class-eq-iff

    forall([s], is-setoid(s) implies forall([a in pts(s), b in pts(s)], class(s, a) = class(s, b) iff related(s, a, b)))

*Warrant (well-known):* (<=) a~b: for any c, b~c iff a~c by transitivity+symmetry, so the two
   separations have the same members; set-extensionality gives [a]=[b].
   (=>) [a]=[b]: a in [a]=[b] (class-self) means a~b.  Uses exactly the three
   equivalence laws folded into IS-SETOID.

### descend-computes

    forall([s], is-setoid(s) implies forall([z, f], f in fun(pts(s), z) and respects(s, f) implies forall([a in pts(s)], (descend(f))(class(s, a)) = f(a))))

*Warrant (well-known):* Lambda-beta: DESCEND(f)([a]) = IOTA z. exists a' in [a]. z = f(a').  Since
   a in [a] (class-self), f(a) satisfies the body.  For uniqueness: any a' in
   [a] has a~a', so f(a')=f(a) by RESPECTS; the body pins z = f(a) uniquely,
   and IOTA returns it.  Representation-independent -- the value never depends
   on which member is named.

### descend-in-fun

    forall([s], is-setoid(s) implies forall([z, f], f in fun(pts(s), z) and respects(s, f) implies descend(f) in fun(quotient(s), z)))

*Warrant (well-known):* Every element of QUOTIENT(s) is some [a] with a in PTS(s) (it is the image of
   PROJ); on it DESCEND(f) returns f(a) in Z (descend-computes), well-defined
   by RESPECTS.  So DESCEND(f) is total QUOTIENT(s) -> Z.

### quotient-universal

    forall([s], is-setoid(s) implies forall([z, f], f in fun(pts(s), z) and respects(s, f) implies forsome([g in fun(quotient(s), z)], forall([a in pts(s)], g(class(s, a)) = f(a)) and forall([g_], g_ in fun(quotient(s), z) and forall([a in pts(s)], g_(class(s, a)) = f(a)) implies g_ = g))))

*In words:* For a setoid s and a function f from its carrier to Z that respects the equivalence (equivalent inputs give equal outputs): there is exactly one function g on the quotient PTS(s)/~ with g([a]) = f(a) for every a.  The universal property of the quotient -- f factors uniquely through the projection.

*Warrant (well-known):* EXISTENCE: take g = DESCEND(f); descend-in-fun types it and descend-computes
   gives the factorization g([a])=f(a).  UNIQUENESS: any g' factoring f agrees
   with g on every [a] (both equal f(a)); every element of QUOTIENT(s) is such
   an [a] (image of PROJ), so g' and g agree everywhere on QUOTIENT(s) and are
   equal by function extensionality.  This is what makes X |-> X/REL a functor:
   the concrete quotient has the defining mapping property.  Capstone asserted
   with a faithful sketch over the installed CLASS/QUOTIENT/PROJ/DESCEND
   supports, in the prod-of-sums-expansion / binomial-theorem library style --
   the machinery is the deliverable, the QED induction-free factorization
   argument is the deferred tactic grind, with no missing primitive.
