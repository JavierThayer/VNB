# VNB operator census

Auto-generated by `(write-operators-md)`.  Every registered operator head, classified per the VNB taxonomy.

- A **function** is an operator `f` with `forsome([A in Set, B in Set], f in FUN(A, B))` — a single set-to-set map.  Almost no *named head* qualifies: each library constructor takes a structure/class argument, so its domain is a proper class.  (The numeric formers `exp`/`sin`/`cos`/… are genuine set-functions on `RR`, but are taken as **primitive** here — part of the numeric base, not library definitions.)  Otherwise functions are TERMS (elements of `FUN(A,B)`), usually the value of a functoid.
- A **functoid** is a term-valued operator that is not a function.  Its value may itself be a function — then it is *function-valued*, still a functoid.
- A **predicate** is proposition-valued.
- A **primitive** is a foundational term-former (kernel + base set theory + arithmetic).

Every operator must be declared (a def-form, a recursion, or a characterizing axiom).  An **undeclared** head is a defect.
