# VNB functoids

Auto-generated by `(write-functoids-md)`.  63 set/structure-valued + 86 value functoids.

Functoids are unfold-only constructors (`def-functoid`): a macete rewrites `name(args)` to its body.  We write `name(params) := body` for that defining unfold — `:=` is a *definitional rewrite* ("is defined as"), NOT an object-level equation; the body is total (it unfolds for any arguments, the typing/meaning living in the warranted support lemmas).  They appear in no other index — `def-constant`/`def-predicate` go to `DEFINITIONS.md`, `def-structure`/`def-functor` to `STRUCTURE-INDEX.md`.  Split below by *return type* (a syntactic split, NOT a categorical one).

## Set- & structure-valued functoids

Body builds a tuple (`list`) or a set (`sep`, `image`, …).  A few are the object map of a genuine functor — `quotient` (setoid ↦ quotient set, with `descend` the morphism map), `completion`, `ring-prod`, the `*-metric-space` bridges; the rest (`class`, `ball`, `preimage`, `choose-set`, …) are set-valued *constructions*, not functors.  `class(s,a)` in particular is element-indexed: the value `proj(s)(a)` of the quotient morphism, not a functor.

## Value functoids

Body is a **term**, not a set/tuple: a function (`vnb-lambda`), an element, or a number — distance sequences, embeddings, ring powers, counts.  A functoid is *never* proposition-valued (that would be a predicate, see `DEFINITIONS.md`); when the body is a `vnb-lambda` the functoid is **function-valued** but is itself still a functoid (its argument ranges over a class).  For the full operator taxonomy see `OPERATORS.md`.

    ptwise-scale(omega, c, f) := vnb-lambda(x_, omega, etimes(c, f(x_)))

### ptwise-sup

    ptwise-sup(omega, cf) := vnb-lambda(x_, omega, esup(image(vnb-lambda(n_, nn, (cf(n_))(x_)), nn)))

### related

    related(s, a, b) := [a, b] in rel(s)

### respects

    respects(s, f) := forall([a in pts(s), b in pts(s)], related(s, a, b) implies f(a) = f(b))

### respects2

    respects2(s, f) := forall([a, b, a_, b_], a in pts(s) implies b in pts(s) implies a_ in pts(s) implies b_ in pts(s) implies related(s, a, a_) and related(s, b, b_) implies f(a, b) = f(a_, b_))

### ring-power

    ring-power(r, x, n) := mpow(commutative-ring-multiplicative-cm(r), x, n)

### seg-curve

    seg-curve(m, f, a, eta) := vnb-lambda(u_, rr, f((vadd(m))(a, (act(m))(u_, eta))))

### seq-limit

    seq-limit(f) := if(converges(rr-ms, f), iota(lm_, converges-to(rr-ms, f, lm_)), 0)

### series-limit

    series-limit(f) := iota(lm_, series-converges-to(f, lm_))

### series-partial-sum

    series-partial-sum(f, k) := sum-ag(normed-field-additive-ag(rr-normed-field), f, k)

### snoc-col

    snoc-col(w, n, x) := matof(succ(n), 1, vnb-lambda([i_, j_], cartesian(interval(1, succ(n)), interval(1, 1)), if(i_ = succ(n), x, entry(w, i_, 1))))

### snoc-row

    snoc-row(c, n, r) := matof(1, succ(n), vnb-lambda([i_, j_], cartesian(interval(1, 1), interval(1, succ(n))), if(j_ = succ(n), r, entry(c, 1, j_))))

### sqrt

    sqrt(a_) := iota(x_, x_ in rr and 0 <= x_ and x_ * x_ = a_)

### submat

    submat(s, p, q) := matof(p, q, vnb-lambda([i, j], cartesian(interval(1, p), interval(1, q)), entry(s, succ(i), succ(j))))

### subseq

    subseq(f, phi) := vnb-lambda(k, nn, f(phi(k)))

### taylor-poly

    taylor-poly(f, a, n, x) := series-partial-sum(vnb-lambda(k, nn, ((nth-deriv(f, k))(a) * (x - a) ^ k) * recip(factorial(k))), succ(n))

### unitrow

    unitrow(a, n, i) := matof(1, n, vnb-lambda([rw, cl], cartesian(interval(1, 1), interval(1, n)), if(cl = i, one(a), zero(a))))

### zeromat

    zeromat(a, m, n) := matof(m, n, vnb-lambda([i, j], cartesian(interval(1, m), interval(1, n)), zero(a)))
