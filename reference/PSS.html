Warrant (well-known): A real number that is <= every positive real is <= 0 -- the real line has no smallest positive element. The order-density / archimedean face of completeness; standard.

rr-le-from-diff-nonneg

Warrant (well-known): 0 <= y-x gives x <= y. Add x to both sides of 0<=y-x (rr-leq-add-compatible) and simplify y-x+x=y. The standard `move everything to one side' step that reduces an inequality goal to a nonnegativity goal.

rr-le-lt-trans

Warrant (well-known): x <= y < z gives x < z (symmetric to rr-lt-le-trans).

Warrant (well-known): x<=y means 0<=y-x; with 0<=c, mul-nonneg gives 0<=c(y-x)=cy-cx, i.e. cx<=c*y.

rr-le-trans

forall([x in rr, y in rr, z in rr], x <= y and y <= z implies x <= z)

Warrant (well-known): Non-strict order is transitive: x <= y <= z gives x <= z (rr-leq-transitive).

Warrant (proof): Curried rr-le-trans: x<=y then y<=z gives x<=z. Same fact, no AND antecedent.

rr-lt-add

Warrant (well-known): A strict and a non-strict inequality add to a strict one: x+u < y+u <= y+v.

rr-lt-implies-le

Warrant (well-known): x < y is (x <= y and x =/= y) by definition, so in particular x <= y.

rr-lt-le-trans

forall([x in rr, y in rr, z in rr], x < y and y <= z implies x < z)

Warrant (well-known): x < y <= z gives x < z (transitivity; x=z would force y=x against x<y).

rr-lt-scale-pos

forall([c in rr, x in rr, y in rr], 0 < c and x < y implies c * x < c * y)

Warrant (well-known): Multiplying a strict inequality by a strictly positive c keeps it strict (c*(y-x) > 0 since both factors are > 0).

rr-lt-trans

forall([x in rr, y in rr, z in rr], x < y and y < z implies x < z)

Warrant (well-known): Strict order is transitive: from x<y<z, x<=z by rr-leq-transitive and x=/=z (else y would be both > and < x).

rr-pos-halvable

Warrant (well-known): Every positive real eps can be halved: there is a positive d with d + d = eps. Standard (d = eps/2).

rr-pos-shrink

Warrant (well-known): Every positive real eps has a smaller positive real below it (e.g. eps/2 < eps). Order density of the reals at 0; standard.

rr-qm-am-2

forall([a in rr, b in rr], (a + b) * (a + b) <= 2 * (a * a + b * b))

Warrant (well-known): Power-mean (QM >= AM) in square form: (a+b)^2 <= 2(a^2+b^2). Equivalent to (a-b)^2 >= 0; closed by (sos "a - b"). The n=2 case of Cauchy-Schwarz with the all-ones vector.

rr-sq-nonneg

forall([x in rr], 0 <= x * x)

Warrant (well-known): 0 <= xx for every real. If 0<=x, mul-nonneg gives 0<=xx; if x<=0 then 0<=(-x) and 0<=(-x)(-x)=xx. The base square-positivity fact; the seed of every sum-of-squares inequality (Cauchy-Schwarz, AM-GM, x*y<=x^2+y^2).

Warrant (well-known): Young's inequality at p=q=2: a*b <= (a^2+b^2)/2 for all real a,b. Equivalent to (a-b)^2 >= 0; closed in one step by (sos "a - b").

Warrant (well-known): SERIES-PARTIAL-SUM f (succ k) = SERIES-PARTIAL-SUM f k + f(k) (the SUM-AG recurrence), and f(k) >= 0, so the partial sums are nondecreasing.

Warrant (well-known): Telescoping. For m <= n the triangle inequality gives d(f m, f n) <= sum_{k=m}^{n-1} d(f k, f(succ k)) <= sum_{k=m}^{n-1} rad(k) = P(n) - P(m), where P is the partial-sum sequence of rad.
